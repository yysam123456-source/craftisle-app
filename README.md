## Architecture Highlights

### Client-Side Processing
All tool processing happens **100% in the browser** using Web APIs:
- `FileReader` / `FileWriter` APIs
- `Canvas` API for image processing
- `Web Workers` for heavy computations
- `IndexedDB` for local storage

**Benefits:**
- ✅ Zero server cost for processing
- ✅ User files never leave their device (privacy)
- ✅ Works offline (PWA-ready)
- ✅ No file size limits from server uploads

### Multi-Site Architecture
Deployed as multiple subdomains via Vercel:
```
www.craftisle.com      # Main site & tool hub
pdf.craftisle.com      # PDF tools (specialized)
resume.craftisle.com   # Resume builder
viewer.craftisle.com   # File viewer
draw.craftisle.com     # Whiteboard
imgprompt.craftisle.com # AI image prompt tool
game.craftisle.com     # HTML5 games
```

## Getting Started (Local Development)

### Prerequisites
- Node.js 18+
- pnpm (recommended) or npm
- PostgreSQL (for Prisma)

### Install & Run

```bash
# Clone the repo
git clone https://github.com/yysam123456-source/craftisle-app.git
cd craftisle-app

# Install dependencies
pnpm install

# Set up environment variables
cp .env.example .env.local
# Edit .env.local with your values

# Run Prisma migrations
pnpm prisma:migrate

# Start dev server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
