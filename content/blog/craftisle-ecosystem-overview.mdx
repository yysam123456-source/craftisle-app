## What is Craftisle?

Craftisle is a comprehensive **free online tools platform** that brings together 135+ browser-based utilities across 4 specialized products. Every tool runs entirely in your browser — no data is ever uploaded to a server, no signup is required, and everything is free forever.

### 2. PDF Tools (pdf.craftisle.com)

A dedicated **67-tool PDF processing suite** built on pdf-lib and qpdf.wasm. All processing happens client-side via WebAssembly, meaning your sensitive documents never leave your device.

**Organize & Manage (24 tools):** Merge, split, extract pages, organize, delete pages, OCR, alternate merge, add/extract attachments, rotate, overlay, N-up layout, grid combine, booklet maker.

**Edit & Annotate (16 tools):** Full PDF editor, sign, crop, bookmark, table of contents, page numbers, watermark, header/footer, invert colors, stamps, form filler & creator, remove annotations.

**Convert to PDF (18 tools):** Convert from JPG, PNG, WebP, SVG, BMP, HEIC, TIFF, Word, Excel, PPT, EPUB, MOBI, Markdown, email, and more.

**Convert from PDF (13 tools):** Export to JPG, PNG, WebP, TIFF, SVG, Word, Excel, PPT, JSON, Markdown, CBZ, extract images, extract tables.

**Optimize & Repair (10 tools):** Compress, fix page size, linearize, repair, deskew, PDF/A conversion, font to outline, OCG layer management.

**Secure (9 tools):** Encrypt, decrypt, sanitize, redact, flatten, remove metadata, change permissions, digital sign, validate signature, timestamp.

### 3. File Viewer (viewer.craftisle.com)

Preview **100+ file formats** directly in your browser — no installation needed. Five specialized viewers:

- **PDF Viewer** — Full PDF rendering with zoom, rotation, search
- **DOCX Viewer** — Word documents with formatting preserved
- **XLSX Viewer** — Excel spreadsheets with formula support
- **PPTX Viewer** — PowerPoint presentations with animations
- **3D & CAD Viewer** — STL, OBJ, GLTF, DWG, DXF, and more

Also supports images (PNG, JPG, SVG, WebP, PSD, AI), code files (JSON, XML, YAML, HTML, CSS, JS, TS, Python), and data formats (CSV, TSV).

### 4. Resume Builder (resume.craftisle.com)

A **privacy-first resume creation tool** built on Reactive Resume. All data stays in your browser's localStorage — no account required.

- Rich text editing with 15+ section types
- Multiple professional templates
- Real-time preview
- Export to PDF and DOCX
- Keyboard shortcuts for efficient editing
- Dark/light theme support
