You have a PDF that needs compressing, an image that needs resizing, and a JSON file that needs formatting. You could install three different apps. Or you could open three browser tabs.

That's why Craftisle exists.

## The four products

Craftisle runs four things:

**craftisle.com** — the main site. 62 tools, 10 categories. Image editing, text formatting, encryption, developer utilities. Each tool is a single page. No wizards, no onboarding flow.

**pdfcraft.app** — 67 PDF-specific tools. Merge, split, compress, OCR, sign. Uses pdf-lib and qpdf.wasm. Everything runs in your browser. Good for documents under 50MB.

**viewer.craftisle.com** — opens 100+ file formats without the native app. PSD, AI, EPS, DWG, RAW photos. Built on the FlyFish viewer engine. Files stay client-side.

**resume.craftisle.com** — resume builder based on Reactive Resume. Stores data in localStorage. Exports to PDF and DOCX. No account needed.

## What you actually get (and what you don't)

The pitch is "135+ tools, all free." Here's the honest version:

- **All 62 main site tools are free, no limits.** No daily caps, no paywalls.
- **pdfcraft handles most PDF tasks under 50MB.** Above 100MB, expect slowness — pdf-lib loads the whole file into memory.
- **viewer.craftisle.com opens the formats it claims to.** DWG and PSD rendering isn't pixel-perfect like the native apps, but it's close enough for preview.
- **resume templates are solid but not infinite.** 3-4 templates, not 50. They're ATS-friendly and clean, not fancy.

## Where things break

Known issues:
- Mobile layout: tools work on phones but the UI wasn't designed for small screens. Image tools are usable; PDF tools are not.
- Batch processing: one file at a time on the main site. pdfcraft has batch merge, but no batch resize/convert yet.
- Offline: needs an internet connection. Service worker is on the roadmap.
