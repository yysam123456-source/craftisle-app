Every developer needs a toolkit of reliable utilities they can reach for without friction. Craftisle's developer tools provide exactly that — **28 free, browser-based tools** covering encryption, formatting, conversion, testing, and generation. No installs, no accounts, no limits.

## Encryption & Hashing (4 tools)

### AES/DES Encrypt
Full symmetric encryption with support for AES and DES algorithms. Choose between ECB and CBC modes with 128/192/256-bit keys. Encrypt and decrypt text or files entirely in your browser.

**Use case:** Encrypt configuration values, API keys, or sensitive data before storage.

### Bcrypt Hash
Industry-standard password hashing with adjustable cost factor. Generate bcrypt hashes for authentication systems. Verify passwords against existing hashes.

**Use case:** Hash passwords during development or generate test data for auth systems.

### Hash Tool
Compute MD5, SHA-1, SHA-256, SHA-512, and RIPEMD-160 hashes. File hashing with drag-and-drop support. Verify file integrity or generate checksums.

**Use case:** Verify downloaded file integrity or generate content hashes.

### JWT Decoder
Decode JSON Web Tokens to inspect header, payload, and signature. View claims, expiration, and issuer information. Validate token structure.

**Use case:** Debug authentication issues or inspect API tokens during development.

## Formatters (5 tools)

### JSON Formatter
Beautify, minify, and validate JSON with tree view navigation. Collapsible nodes for large objects. Copy formatted output with one click. **Most popular tool on Craftisle.**

### HTML Formatter
Format HTML code with proper indentation. Supports JSX syntax. Minify option for production optimization.

### SQL Formatter
Format SQL queries with configurable keyword casing (UPPER/lower). Handles nested queries, CTEs, and complex joins.

### YAML Formatter
Validate and format YAML. Perfect for Kubernetes manifests, GitHub Actions workflows, and Docker Compose files.

### HTML Escape
Escape and unescape HTML special characters. Essential for preventing XSS vulnerabilities and encoding user-generated content.
