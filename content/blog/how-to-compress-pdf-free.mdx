## Method 2: Use "Print to PDF" (Quick, No Tool Needed)

If you only need to compress one PDF and don't want to use any tool:

### Step 1: Open PDF in Chrome/Safari

Right-click PDF → "Open with" → Chrome (or Safari).

### Step 2: Print to PDF

Press `Ctrl+P` (Windows) or `Cmd+P` (Mac).

### Step 3: Adjust Settings

- **Destination**: "Save as PDF"
- **Pages**: "All" (or select specific pages)
- **Paper size**: "Fit to page"
- **Quality**: "Draft" (for smallest file size)

### Step 4: Save

Click "Save". Your new PDF will be 50-70% smaller.

**Limitation**: This method only works for PDFs with images. For text-heavy PDFs, use Method 1.

## Common Mistakes to Avoid

### ❌ Mistake 1: Using Cloud Tools for Sensitive Documents

Cloud tools (SmallPDF, iLovePDF) upload your files to their servers. If your PDF contains:
- Contracts
- Tax documents
- Medical records
- Business reports

**Don't use cloud tools**. Use browser-based tools like Craftisle (files never leave your computer).

### ❌ Mistake 2: Over-Compressing (Making PDF Unreadable)

If you compress too much, text becomes unreadable and images become pixelated.

**Solution**: Use "Medium Compression" (96 DPI) for most use cases. Only use "High Compression" (72 DPI) for archiving.

### ❌ Mistake 3: Not Checking File Size After Compression

Sometimes compression doesn't reduce file size much (if the PDF is already optimized).

**Solution**: Check file size before and after. If reduction is less than 20%, the PDF might already be optimized.

### ❌ Mistake 4: Compressing Already Compressed PDFs

Compressing a PDF that's already compressed can make quality worse without reducing file size much.

**Solution**: Only compress the original, high-quality PDF.
