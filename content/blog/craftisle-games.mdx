Someone on the team spent a weekend building a procedural island generator in Three.js. It went into the "fun projects" folder. Then we realized: "Wait, people might actually enjoy playing this."

Now Craftisle has three browser games. They're small, they're simple, and they run in a tab.

## Island Builder

→ [Play Island Builder](/play/island-builder) | [More Free Games](/games)

Procedurally generated islands using Perlin noise. Each refresh creates a new island with randomized terrain — hills, beach, water, trees. You can orbit, pan, and zoom with mouse/touch controls.

Built on Three.js. The water shader uses a simple Sine-wave animation. The island mesh is a height map generated from layered noise functions. Total bundle: about 2MB.

It's a sandbox, not a game with objectives. No scores, no resources, no enemies. Just a satisfying 3D scene to explore. People use it as a desktop background loop.

## The Last Glimmer

A top-down survival shooter. Waves of enemies, pick up ammo and health, survive as long as you can. 2D pixel-art style built with Canvas API.

Keyboard controls: WASD to move, mouse to aim and shoot. The difficulty ramps up every wave. Most people last 3-5 waves on their first try. The high score resets on page refresh — no persistent leaderboard.

## Tiny World Builder

A tiny city builder. Place buildings on a green island grid, watch the city grow. Each building type has a cost in "coins" that regenerate over time. No disasters, no resource chains, no tech tree — pure casual building.

Built as a weekend project. 2D top-down view. Buildings include houses, shops, farms, factories, parks. The simulation is minimal — population counts building types.

## What these games share

They're all open-source (included in the main repo under `/app/(marketing)/games/`). Contributions welcome.
