## How to Merge PDF on macOS (Without Any Tool)

If you have a Mac, you can merge PDFs using Preview (built-in app):

### Step 1: Open First PDF in Preview

Right-click PDF → "Open With" → "Preview".

### Step 2: Open Thumbnail Sidebar

Click "View" → "Thumbnails".

### Step 3: Drag and Drop Other PDFs

1. Open second PDF in Preview
2. Select all pages in thumbnail sidebar (`Cmd+A`)
3. Drag and drop them into the first PDF's thumbnail sidebar
4. Repeat for all PDFs

### Step 4: Save

File → Save. Your merged PDF is ready.

**Limitation**: This method is slow for 10+ PDFs.

## How to Merge PDF on Windows (Without Any Tool)

Windows doesn't have a built-in PDF merger. You need either:

### Method 1: Use Print to PDF (Quick, Free)

1. Open all PDFs in Chrome/Safari
2. Print each one to PDF (`Ctrl+P` → "Save as PDF")
3. Now you have multiple PDFs that can be merged using online tool

### Method 2: Use PDFtk (Free, Command Line)

```bash
# Install PDFtk
sudo apt-get install pdftk  # Ubuntu
brew install pdftk-java  # macOS

# Merge PDFs
pdftk file1.pdf file2.pdf file3.pdf cat output merged.pdf
```

## Common Mistakes to Avoid

### ❌ Mistake 1: Merging Scanned PDFs Without OCR

If your PDFs are scanned images (not searchable text), merging them won't make the text searchable.

**Solution**: Use [PDF OCR](https://pdf.craftisle.com/tools/pdf-ocr) before merging.

### ❌ Mistake 2: Merging PDFs with Different Page Sizes

If File 1 is A4 (210x297mm) and File 2 is Letter (216x279mm), the merged PDF will have inconsistent page sizes.

**Solution**: Use [PDF Page Resizer](https://pdf.craftisle.com/tools/pdf-page-resizer) to unify page sizes before merging.

### ❌ Mistake 3: Not Checking Order Before Merging

If you merge files in wrong order, you'll have to re-merge.

**Solution**: Use drag-and-drop reordering in our tool to confirm order before merging.
