### Data Sources

The directory aggregates and curates resources from four major open-source lists:

1. **FMHY (6,187 resources)** — The largest community-maintained collection of free resources
2. **Free-for.dev (57 categories)** — SaaS, PaaS, and IaaS offerings with free tiers
3. **Awesome Self-Hosted (83 categories)** — Self-hosted alternatives to popular SaaS products
4. **Public APIs (51 categories)** — Free APIs for development and testing

Each resource is verified for:
- Active maintenance and recent updates
- Genuinely free offering (not just a free trial)
- Community reputation and GitHub stars (where applicable)
- Quality of documentation and developer experience

## How to Use the Directory

### Browse by Domain

Start by selecting a domain that matches your needs. Each domain page shows:
- All subcategories with resource counts
- Top-rated and most popular resources
- Recently added and updated entries
- Quick filters for platform, pricing model, and license type

### Search with Filters

The advanced search supports:
- **Keyword search** — Find resources by name, description, or tags
- **Category filter** — Narrow by domain and subcategory
- **Source filter** — Filter by data source (FMHY, Free-for.dev, etc.)
- **Sort options** — By popularity, rating, or recency

### Resource Detail Pages

Each resource has a dedicated page with:
- **Full description** — What it does and why it's useful
- **Pricing details** — Free tier limits and paid plan info
- **Alternatives** — Similar resources for comparison
- **External links** — Direct links to the resource and its documentation
- **Community notes** — Tips and caveats from the community
