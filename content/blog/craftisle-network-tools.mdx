Craftisle's network tools provide essential networking utilities that every developer and DevOps engineer needs — running 100% in your browser with zero network calls to our servers.

## All 3 Network Tools

### 1. IP Calculator

A full-featured IPv4 and IPv6 subnet calculator that shows everything you need for network planning:

**IPv4 Features:**
- **CIDR notation support** — Enter `192.168.1.0/24` and get instant results
- **Subnet mask input** — Also accepts traditional mask format (`255.255.255.0`)
- **Network address** — The base address of the subnet
- **Broadcast address** — The all-hosts broadcast address
- **Usable host range** — First and last assignable IPs
- **Total hosts** — Including network and broadcast addresses
- **Wildcard mask** — For ACL and OSPF configurations
- **Binary representation** — See the actual bit patterns

**IPv6 Features:**
- Full IPv6 address parsing with shorthand expansion
- Prefix length support (`/32`, `/48`, `/64`, etc.)
- IPv6 subnet calculation with correct EUI-64 conventions

**Real-world use cases:**
- Planning AWS VPC subnets (`/16` to `/28` ranges)
- Configuring firewall allow/deny rules with correct CIDR blocks
- Setting up Kubernetes pod and service CIDR ranges
- Network documentation and architecture diagrams

### 2. IP & Radix Converter

A dual-purpose tool that combines IP conversion with base/radix conversion:

**IP Conversion:**
- IPv4 to decimal, hex, binary, and octal
- IPv6 to full hex and compressed formats
- Reverse: enter decimal and get dotted-decimal IP

**Radix Converter:**
- Convert numbers between bases 2 (binary) through 36
- Live preview as you type
- Support for large integers (BigInt)
- Useful for: understanding bitmasks, encoding IDs, and working with non-decimal number systems

### 3. User-Agent Parser

Parse and analyze browser user-agent strings to understand your visitors' environment:

**What it extracts:**
- **Browser** — Name, version, and rendering engine (Chrome, Firefox, Safari, Edge)
- **Operating System** — Windows, macOS, Linux, iOS, Android with version
- **Device type** — Desktop, tablet, mobile, bot/crawler
- **CPU architecture** — x86, ARM, Apple Silicon
- **Layout engine** — Blink, Gecko, WebKit

**Why it matters:**
- Debug browser-specific bugs by identifying the exact browser/OS combination
- Test responsive design breakpoints based on device type
- Understand your analytics data by parsing raw user-agent strings
- Identify bot traffic patterns in your access logs

## Security & Privacy

All IP calculations and user-agent parsing happen entirely in your browser. No network data is sent to any server. This is critical because:
- Subnet configurations may reveal internal network topology
- User-agent strings can contain identifying information
- All computation is local — instant results, zero latency
