Craftisle's image tool suite is one of the most comprehensive collections of **free online image editors** available. Every tool runs entirely in your browser using WebAssembly and modern Canvas APIs — no files are ever uploaded to a server.

## All 17 Image Tools

### 1. Image Resizer
Resize images by exact dimensions or percentage. Supports width, height, and fit modes (cover, contain, fill). Perfect for preparing images for web, social media, or print.

### 2. Image Cropper
Interactive crop tool with precise pixel-level control. Drag to select your crop area and export in any format. Built on react-image-crop for smooth interactions.

### 3. Image Compressor
Reduce file size while maintaining quality. Adjustable compression levels with real-time preview. Supports JPEG, PNG, WebP, and AVIF output formats.

### 4. Image Converter
Convert between image formats instantly. Supported formats: **JPEG, PNG, WebP, AVIF, TIFF, BMP**. Batch conversion support with quality control.

### 5. Image Rotator
Rotate images by any angle — not just 90° increments. Flip horizontally or vertically. Real-time preview before export.

### 6. Color Palette Extractor
Extract the dominant color palette from any image. Returns hex codes and color distribution data. Great for brand color extraction and design inspiration.

### 7. Favicon Generator
Generate favicon sets from any image. Creates multiple sizes (16×16, 32×32, 48×48, 64×64, 128×128, 256×256) plus Apple touch icons. Perfect for websites and PWA manifest.

### 8. Strip Metadata
Remove EXIF, GPS, camera info, and other metadata from images. Essential for privacy before sharing photos online. Batch processing supported.

### 9. Image Info
View detailed image properties — dimensions, format, file size, color depth, metadata, and EXIF data. Quick inspection without opening an image editor.

### 10. Image Border
Add customizable borders to images. Control border width, color, and style. Perfect for framing photos or creating consistent image styling.

### 11. Watermark
Add text watermarks to protect your images. Customize font, size, color, opacity, and position. Ideal for photographers and content creators.

### 12. Color Adjust
Fine-tune brightness, contrast, saturation, and hue. Real-time preview with sliders for each parameter. Non-destructive editing.

### 13. Passport Photo Generator
Create passport and visa photos that meet official requirements. Automatic face detection, background removal, and size compliance for multiple countries.

### 14. Meme Generator
Create custom memes with top and bottom text. Classic meme formatting with font controls. Add your own images or use templates.

### 15. Beautify Screenshots
Transform plain screenshots into polished marketing images. Add shadows, rounded corners, backgrounds, and padding. Perfect for documentation and social media.

### 16. Find Duplicates
Detect duplicate or near-duplicate images using perceptual hashing (pHash). Compare image content regardless of resolution or minor edits. Batch scan entire folders.

### 17. Create GIF
Combine multiple images into animated GIFs. Control frame delay, loop count, and output quality. Create simple animations without specialized software.

## Tips for Best Results

1. **Use WebP for web** — WebP offers 25-35% smaller files than JPEG at the same quality
2. **Strip metadata before sharing** — Remove GPS coordinates and camera info for privacy
3. **Compress before uploading** — Reduce file size before uploading to websites or social media
4. **Convert to AVIF for next-gen web** — AVIF provides even better compression than WebP
5. **Use perceptual hashing for dedup** — Find duplicates even when images have been resized or lightly edited
