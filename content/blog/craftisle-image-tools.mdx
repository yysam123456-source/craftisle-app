Someone on Reddit asked: "Is there a free image resizer that doesn't make me upload my photos to some sketchy server?" That's the question half our image tools answer.

Here's what each tool actually does, and what it doesn't.

## The tools

**Image Resizer** — enter width/height in pixels or pick a percentage. Supports cover/contain/fill modes. Good for social media prep. Bad for upscaling (Canvas API blurs at 2x+).

**Image Cropper** — drag a rectangle, export. Uses react-image-crop. Precise to the pixel.

**Image Compressor** — adjust quality slider, preview in real time. Outputs JPEG/PNG/WebP/AVIF. A 5MB JPEG typically drops to 300-800KB at quality 70. Don't go below 50 — artifacts become visible. Compare with [PDF Compress](https://pdf.craftisle.com/compress-pdf) if you're working with PDF documents instead.

**Image Converter** — converts between JPEG, PNG, WebP, AVIF, TIFF, BMP. One file at a time. PNG → WebP usually cuts file size by 60-80%.

**Image Rotator** — any angle rotation, horizontal/vertical flip. Quick, no frills.

**Color Palette Extractor** — drop an image, get hex codes for the top 5-10 colors. Useful for matching brand colors from a screenshot. Not useful for precise color analysis — it averages clusters.

**Favicon Generator** — generates 16×16 through 256×256 PNGs plus Apple touch icons from one image. Ready for your `<link rel="icon">` tag.

**Strip Metadata** — removes EXIF, GPS, camera model, date taken. Batch mode available. Before posting photos to public forums, run them through this. GPS coordinates in EXIF have doxed people. Also check our [Privacy Policy](/privacy) to learn how we protect your data.

**Image Info** — shows dimensions, format, file size, color depth, all EXIF data. Quick inspection, no editing.

**Image Border** — adds borders with configurable width, color, style. Simple and predictable.

**Watermark** — text overlays with font/size/color/opacity/position controls. Image-based watermarks coming later.

**Color Adjust** — brightness, contrast, saturation, hue sliders. Non-destructive (works on a copy). Not a full photo editor — no curves, no levels, no masks.

**Passport Photo Generator** — auto face detection, background removal, size presets for multiple countries. Works best with front-facing, well-lit photos against plain backgrounds. Won't handle group photos or side profiles well.

**Meme Generator** — top/bottom text, Impact-style font. Upload your own image or pick from templates. Does exactly what you expect.

**Beautify Screenshots** — adds shadows, rounded corners, backgrounds, padding to screenshots. Turns a raw screenshot into a shareable social media image in 3 clicks. One of our most-used tools.

**Find Duplicates** — uses perceptual hashing (pHash) to find near-duplicate images. Scans a folder, returns groups of similar images. Won't catch heavily edited images — cropping or filters reduce hash match below threshold.

**Create GIF** — combine multiple images into an animated GIF. Set frame delay and loop count. Simple frame sequencing — no transitions, no effects, no video import.

## What these tools share

All 17 use the Canvas API in your browser. File size is limited by available memory — Chrome typically handles images under 50MB smoothly. Safari has tighter Canvas memory limits on iOS.
