Craftisle's text tools are designed for developers and writers who need quick, reliable text manipulation without installing software. Every tool runs entirely in your browser — no data leaves your device.

## All 4 Text Tools

### 1. Case Converter

Instantly convert text between **all major naming conventions**. Paste once, get all formats simultaneously:

| Format | Example | Common Use |
|--------|---------|-----------|
| **camelCase** | `myVariableName` | JavaScript, Java, Go |
| **PascalCase** | `MyClassName` | C#, TypeScript classes, React components |
| **snake_case** | `my_variable_name` | Python, Ruby, Rust, SQL column names |
| **CONSTANT_CASE** | `MY_CONSTANT` | Environment variables, C/C++ constants |
| **kebab-case** | `my-variable-name` | CSS classes, URLs, CLI flags |
| **dot.case** | `my.variable.name` | Configuration keys, Java packages |

**Why you need it:** Moving code between Python (snake_case) and JavaScript (camelCase) is a daily friction for full-stack developers. One paste, one click — all conventions at once.

### 2. Text Formatter

A Swiss Army knife for text with **20+ operations** in a single tool:

- **Word & character count** — Quick statistics for writers and content editors
- **Sort lines** — Alphabetical, reverse, or by length
- **Remove duplicates** — Deduplicate email lists, URLs, product SKUs
- **Trim whitespace** — Remove leading/trailing spaces, normalize line endings
- **Find and replace** — Full regex support for power users
- **Add prefixes/suffixes** — Batch-prepend or append text to every line
- **Number lines** — Add sequential line numbers for code snippets
- **Wrap text** — Reflow long paragraphs to a specified width

**Pro tip:** Use the regex find-and-replace to convert between log formats, clean CSV exports, or normalize API responses in seconds.

### 3. Text Diff

Compare two texts side-by-side with **color-coded differences** using Myers' diff algorithm — the same one Git uses:

- **Side-by-side view** — See original and modified text in parallel panels
- **Inline view** — Differences highlighted within a single unified view
- **Word-level diff** — Highlight changed words, not just entire lines
- **Character-level diff** — For fine-grained comparison of short strings
- **Ignorable whitespace** — Toggle to focus on meaningful changes only
- **Export diff** — Download as a unified diff patch file

**Use cases:**
- Compare configuration files between staging and production
- Review code changes before committing
- Spot differences between contract versions or legal documents
- Debug why an API response changed between deployments

### 4. Unicode Inspector

Explore, search, and convert Unicode characters with full metadata:

- **Character lookup** — Search by name, code point, or paste any character
- **Code point details** — View UTF-8 bytes, UTF-16 bytes, category, block, and script
- **Format conversion** — Convert between `\uXXXX`, `&#xXXXX;`, `U+XXXX`, and raw characters
- **Bidirectional info** — Check if a character is LTR, RTL, or neutral (critical for Arabic/Hebrew layouts)
- **Emoji support** — Full emoji sequence parsing including skin tones, flags, and ZWJ sequences

**Real-world debugging:** When your app shows `□` instead of a character, paste it into the Unicode inspector to see exactly which code point is missing from your font. This tool has saved countless hours debugging CJK, emoji, and RTL text rendering issues.
