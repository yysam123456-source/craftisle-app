Craftisle's PDF and file handling capabilities are split across two specialized subdomains: **pdf.craftisle.com** (67 PDF tools) and **viewer.craftisle.com** (100+ format viewer). Together they cover virtually every document workflow you'll encounter.

## PDF Tools (pdf.craftisle.com)

All 67 PDF tools run on **WebAssembly** via pdf-lib and qpdf.wasm — meaning your documents are processed entirely in your browser. No file uploads, no server processing, no privacy concerns.

### Organize & Manage (24 tools)

**Core Operations:**
- **PDF Multi-Tool** — All-in-one merge, split, organize, rotate, extract, and delete pages
- **Merge PDF** — Combine up to 100 PDFs with drag-and-drop reordering
- **Split PDF** — Split by page ranges or extract individual pages
- **Extract Pages** — Select specific pages with preview thumbnails
- **Organize PDF** — Rearrange, duplicate, and delete pages with visual grid
- **Delete Pages** — Remove unwanted pages with multi-select

**Advanced Operations:**
- **OCR PDF** — Optical character recognition for scanned documents (multi-language)
- **Alternate Merge** — Interleave pages from two PDFs
- **Add/Extract/Edit Attachments** — Embed and manage file attachments
- **Divide Pages** — Split each page horizontally or vertically
- **Rotate Custom** — Rotate by any angle, not just 90° increments
- **Overlay PDF** — Layer one PDF on top of another
- **N-Up Layout** — Print multiple pages per sheet (2-up, 4-up, 6-up, 9-up)
- **Grid Combine** — Arrange multiple PDFs in a custom grid layout
- **Booklet Maker** — Create print-ready booklets with saddle stitch

**Utility:**
- **Add Page Labels** — Roman numerals, prefixes, custom ranges
- **View/Edit Metadata** — Title, author, subject, keywords
- **Posterize PDF** — Split large pages into printable tiles
- **Compare PDFs** — Side-by-side or overlay comparison with diff highlighting

### Edit & Annotate (16 tools)

- **Edit PDF** — Full annotation suite: highlight, underline, strikethrough, shapes, freehand, images, search
- **Sign PDF** — Draw, type, or upload signatures. Multiple signatures per document
- **Crop PDF** — Trim margins across all or selected pages
- **Bookmark Editor** — Add, edit, import, and export PDF bookmarks
- **Table of Contents** — Generate TOC from bookmarks with custom styling
- **Page Numbers** — Add page numbers with custom position, format, and start number
- **Watermark** — Text or image watermarks with opacity, rotation, and position control
- **Header/Footer** — Custom headers and footers with text, dates, and page numbers
- **Form Filler** — Fill PDF forms with XFA support. Save and flatten after filling
- **Form Creator** — Create fillable forms with text fields, checkboxes, and dropdowns
- **Remove Annotations** — Clean up commented PDFs
- **Remove Blank Pages** — Auto-detect and delete empty pages

### Optimize & Repair (10 tools)

- **Fix Page Size** — Standardize to A4, Letter, Legal, or custom dimensions

## File Viewer (viewer.craftisle.com)

Preview **100+ file formats** directly in your browser. Five specialized viewers for different content types.

### PDF Viewer
Full-featured PDF reader with page navigation, zoom (25%-500%), rotation, search, fullscreen mode, and direct download. Renders complex documents with vector graphics and embedded fonts.

### DOCX Viewer
View Word documents with preserved formatting — headers, lists, tables, images, and text styling. No Microsoft Office installation needed.

### XLSX Viewer
Preview Excel spreadsheets with formula evaluation, multiple sheets, merged cells, and conditional formatting. Read-only view for quick data inspection.

### PPTX Viewer
View PowerPoint presentations with slide navigation, animations, speaker notes, and fullscreen presentation mode.

### 3D & CAD Viewer
Interactive 3D model viewing with orbit, pan, and zoom controls. Supported formats:
- **STL, OBJ, PLY** — Standard 3D mesh formats
- **GLTF, GLB** — Modern glTF 2.0 with PBR materials
- **3MF, AMF** — 3D printing formats
- **DWG, DXF** — AutoCAD and CAD exchange formats
- **DAE, FBX** — Collada and Autodesk formats

### Image & Code Viewer
- **Images:** PNG, JPG, GIF, SVG, WebP, BMP, ICO, PSD, AI
- **Code:** JSON, XML, YAML, HTML, CSS, JavaScript, TypeScript, Python
- **Data:** CSV, TSV
