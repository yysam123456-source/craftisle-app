## pdfcraft: 67 PDF tools

All tools use pdf-lib and qpdf.wasm. Both run in your browser via WebAssembly. Files don't leave your machine.

### Organize (24 tools)

The daily drivers:
- **Merge** — combine PDFs with drag-drop reorder. Up to 100 files.
- **Split** — by page range or extract individual pages.
- **Extract Pages** — thumbnails, multi-select.
- **Organize** — rearrange, duplicate, delete in a grid view.
- **OCR** — Tesseract.js under the hood. Multi-language. Scan quality matters — a clean 300 DPI scan OCRs well; a blurry phone photo won't.
- **Alternate Merge, Overlay, N-Up, Grid, Booklet** — specialized layout tools. Booklet maker handles saddle stitch.

### Edit & Annotate (16 tools)

- **Edit PDF** — highlight, underline, strikethrough, shapes, freehand, images. Not a text editor — can't modify existing text inline. Add annotations and new content only.
- **Sign** — draw, type, or upload. Multiple signatures per doc. No digital certificate signing (PKI not supported).
- **Crop, Bookmarks, TOC, Page Numbers, Watermark, Header/Footer** — standard document finishing tools.
- **Form Filler & Creator** — works on XFA forms. Create fillable forms with text fields, checkboxes, dropdowns. Flatten after filling.

### Conversion (31 tools)

Converts **to** PDF from: JPG, PNG, WebP, SVG, BMP, HEIC, TIFF, DOCX, XLSX, PPTX, EPUB, MOBI, Markdown, EML/MSG. 

Converts **from** PDF to: JPG, PNG, WebP, BMP, TIFF, SVG, DOCX, XLSX, PPTX, JSON, Markdown.

Special tools: Extract Images (exports all images as ZIP), Extract Tables (to JSON/Markdown/CSV), AI PDF Reflower (mobile reading reflow).

### Optimize (10 tools)

- **Compress** — configurable level. A 30MB scanned PDF drops to 4-8MB at Medium. Below 3MB, text readability suffers.
- **Linearize** — byte-serving for fast web viewing.
- **Repair** — recovers data from corrupted PDFs. Works on structural damage, not bit flips.
- **PDF/A conversion** — archive-standard with font embedding. Good for long-term document preservation.
- **Font to Outline** — converts text to vector paths. Guarantees rendering but makes the file unsearchable.

### Security (9 tools)

- **Encrypt/Decrypt** — password protection with AES.
- **Sanitize** — strips metadata, annotations, scripts, attachments.
- **Redact** — search and permanently remove text. Unlike annotations, redactions can't be reversed.
- **Flatten** — makes annotations and form fields permanent.
- **Timestamp** — RFC 3161 trusted timestamping.

## What pdfcraft isn't

- **Acrobat replacement.** You can't edit existing PDF text. Annotation only.
- **Unlimited.** PDFs over 100MB will be sluggish — WASM loads the full file into memory.
- **Offline.** Needs initial page load. No service worker yet.
