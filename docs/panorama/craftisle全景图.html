📈 五、广告配置设计（一键开启）
⚙️ 一键开关原理
环境变量 NEXT_PUBLIC_ADSENSE_CLIENT 控制全局广告
留空 = 全站隐藏广告（开发环境自动隐藏）
填入 AdSense Client ID = 全站所有 <AdSlot> 显示广告
无需逐页修改代码，只需改一个环境变量
组件路径：components/ads/AdSlot.tsx
📐 广告位尺寸
leaderboard — 728×90（横幅 Banner）
rectangle — 336×280（内容插入）
halfpage — 300×600（侧边栏）
responsive — 自适应（全宽 90px 高）
使用：<AdSlot slotId="123456" size="leaderboard" />
⚡ 一键开启操作步骤：
1. 登录 Google AdSense 获取 Client ID（格式：ca-pub-xxxxxxxxxxxxxx）
2. 在 Vercel Dashboard → Settings → Environment Variables 添加 NEXT_PUBLIC_ADSENSE_CLIENT=ca-pub-xxx...
3. Redeploy（或等自动重新部署）→ 全站广告自动显示 ✅
