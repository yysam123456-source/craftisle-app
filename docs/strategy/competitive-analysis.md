## 1. Direct Competitors (Resource Directories)

### 1.1 FMHY.net
| Metric | Value |
|--------|-------|
| Traffic (est.) | 500K-2M monthly |
| Content | 6,000+ free resources across 14 categories |
| Monetization | None (community-driven, donation-based) |
| SEO Strategy | GitHub wiki as canonical source; community backlinks from Reddit/Discord |
| Strengths | Largest free resource wiki, strong community, comprehensive piracy-adjacent listings |
| Weaknesses | No tool functionality, wiki-only UX, polarizing content, no commercial model |
| **Craftisle advantage** | Integrated tools (62+), broader scope (4 data sources), better UX, 12-domain taxonomy |

### 1.2 alternativeTo.net
| Metric | Value |
|--------|-------|
| Traffic (est.) | 10M-20M monthly |

| Monetization | Ads, sponsored placements |

| Strengths | Largest alternatives database, user voting/reviews, clean category tree |
| Weaknesses | Slow mobile UX, heavy ad load, limited filtering |
| **Craftisle advantage** | Actual free tools (not just listings), no ads on tools, privacy-first |

| Metric | Value |
|--------|-------|
| Traffic (est.) | 20M+ monthly |

| Strengths | Massive tech audience, launch virality, collections feature |

### Unique Selling Points
1. **Privacy-first architecture** — client-side processing (Web Crypto, WASM) means zero data upload
2. **Unified directory** — 4 data sources in one interface (unique in market)
3. **Actual tools + directory** — no competitor combines a 62-tool suite with a 10K resource directory
4. **Zero paywall** — truly free, no "2 per day" limits
5. **12-domain taxonomy** — more granular than FMHY (14 cats) and alternativeTo (tree-based)

### Growth Opportunities
1. **Long-tail SEO** — 200+ category pages generate programmatic SEO traffic
2. **Cross-linking** — tool pages ↔ resource pages create internal link equity
3. **Community** — GitHub discussions, resource submissions build backlinks
4. **International** — 14-language support unlocks non-English markets
5. **Content marketing** — tool reviews, comparison pages, how-to guides

### Immediate Threats
- iLovePDF/SmallPDF have dominant brand recognition and search rankings
- ProductHunt/AlternativeTo have massive user bases and network effects
- TinyWow is expanding tool coverage aggressively
- AI agents (ChatGPT, Claude) are starting to replace simple online tools
