## Monitoring Setup

### Google Search Console
1. Add `craftisle.app` as property (both domain and URL prefix)
2. Verify via DNS TXT record or HTML meta tag
3. Submit sitemap: `https://craftisle.app/sitemap.xml`
4. Check weekly: Performance → Queries for keyword positions

### Rank Tracking (Manual Monthly)
- Track positions for top 50 keywords above
- Monitor clicks, impressions, CTR, average position
- Focus on keywords at positions 4-15 (highest ROI from optimization)

### Content Gap Analysis
- Identify keywords competitors rank for that we don't
- Prioritize by volume × relevance
- Create content calendar items for top 10 gaps
