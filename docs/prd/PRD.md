## 1. 产品概述

### 1.1 背景
Craftisle 是一个面向海外用户的免费在线工具与游戏平台，采用纯客户端架构（无需注册），通过广告（Google AdSense）和订阅（Stripe）变现。

### 1.2 目标
- **短期 (MVP)**: 上线 58+ 工具页 + 3 个游戏页，通过 SEO 获取自然流量
- **中期 (v1.0)**: 完善用户系统，接入订阅变现
- **长期 (v2.0)**: 成为海外知名的免费工具与游戏平台

### 1.3 目标用户
| 用户群 | 特征 | 痛点 |
|--------|------|------|
| 普通用户 | 需要快速完成简单任务（图片处理、PDF 转换等） | 不想安装软件、不想注册 |
| 学生 | 需要免费工具完成作业 | 预算有限 |
| 小商家 | 需要简单工具处理日常事务 | 不想花钱买 Adobe / Office |

## 2. 功能需求

## 3. 非功能需求

### 3.1 性能
- **Core Web Vitals**: LCP <2.5s, FID <100ms, CLS <0.1
- **纯客户端**: 所有工具处理在浏览器端完成，降低服务器成本

### 3.2 安全
- **NextAuth v5**: 安全的身份认证
- **环境变量**: 所有敏感信息存储在 Vercel Dashboard
- **HTTPS**: Cloudflare CDN 强制 HTTPS

### 3.3 SEO
- **站点地图**: 自动生成（next-sitemap）
- **结构化数据**: Schema.org 标记
- **长尾词**: 每个工具页针对 5-8 个长尾词优化

### 3.4 可用性
- **响应式**: 移动端优先，适配所有设备
- **无障碍**: WCAG 2.1 AA 标准
- **深色模式**: 支持浅色/深色主题切换
